# Machine Learning Coursework Analysis

Coursework projects in Python, documented as PDF reports covering methodology, evaluation, and interpretation.

## Contents

1. **Regression and Probability Modelling** (`01_regression_and_probability.pdf`)
Data cleaning, missing values, outlier removal, probability theory (normal fitting, K-S test), linear/polynomial/logistic regression, Ridge/Lasso, residual analysis, ROC-AUC, cross-validation

2. **Comparative Analysis and Evaluation of Classification Algorithms** (`02_classification_and_ensemble.pdf`)
Naive Bayes, SVM, Decision Tree with pruning, Random Forest, Voting and Stacking ensembles, confusion matrix, precision/recall/F1, cross-validation

3. **Dimensionality Reduction and Clustering** (`03_dimensionality_reduction_and_clustering.pdf`)
PCA, t-SNE, explained variance, K-means, DBSCAN, inertia, silhouette score

## Tools

Python (pandas, NumPy, scikit-learn, SciPy, Matplotlib, Seaborn), Jupyter Notebook
