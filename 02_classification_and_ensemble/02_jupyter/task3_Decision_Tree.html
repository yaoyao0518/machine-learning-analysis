Root Node: The decision tree starts at the root node, which contains all the samples (represented by "samples = 398") and splits based on the feature that most effectively separates benign from malignant cases. In this tree, the root node splits on "Feature 8" with a threshold of 0.061. If the feature value is less than or equal to 0.061, the samples are directed to the left branch; otherwise, they go to the right.

Decision Nodes: Each decision node represents a split on a particular feature and threshold, selected to maximize information gain (minimizing Gini impurity). For instance, after the root node, one branch splits on "Feature 21" with a threshold of 0.116, continuing to further divide the samples to refine the classification.

Leaf Nodes: The tree ends at leaf nodes, where the samples are classified as either benign or malignant. Each leaf node provides information on the number of samples in that node, their class distribution (value), and the final predicted class. For example, in the leftmost leaf node, all samples are classified as benign.

Class Labels and Gini Impurity: Each node displays the Gini impurity, a measure of how mixed the classes are within the node. A lower Gini value indicates a purer node (closer to all samples being in one class). Leaf nodes typically have a Gini of 0 or a very low value, showing a strong confidence in the classification.

from sklearn.metrics import accuracy_score, precision_score, recall_score, f1_score, confusion_matrix
import seaborn as sns
import matplotlib.pyplot as plt

# a function to evaluate model performance
def evaluate_model(model, X_test, y_test):
    y_pred = model.predict(X_test)
    accuracy = accuracy_score(y_test, y_pred)
    precision = precision_score(y_test, y_pred)
    recall = recall_score(y_test, y_pred)
    f1 = f1_score(y_test, y_pred)
    conf_matrix = confusion_matrix(y_test, y_pred)
    return accuracy, precision, recall, f1, conf_matrix

# Evaluate the Decision Tree model before pruning
performance_before_pruning = evaluate_model(dt_model, X_test, y_test)
print("Performance before Pruning:")
print("Accuracy:", performance_before_pruning[0])
print("Precision:", performance_before_pruning[1])
print("Recall:", performance_before_pruning[2])
print("F1 Score:", performance_before_pruning[3])

# Plot the confusion matrix

plt.xlabel("Predicted Label")
plt.ylabel("Actual Label")

Pre-Pruning¶

Pre-pruning halts tree growth early based on specific criteria, such as maximum depth or minimum samples per leaf. This approach simplifies the model from the outset, preventing excessive complexity.

Post-Pruning¶

Post-pruning first grows a full tree and then selectively trims branches using the cost complexity parameter. In post-pruning, the ccp_alpha (cost complexity parameter) controls the extent of pruning, with higher values resulting in a simpler, more pruned tree to mitigate overfitting.

The process for selecting the optimal ccp_alpha involves two steps: first, generating a range of possible ccp_alpha values using cost_complexity_pruning_path; then, training models for each value and selecting the one that yields the best performance, such as the highest F1 score, on cross-validation or test data. This approach helps achieve a balance between model simplicity and predictive accuracy.

# Post-Pruning: cost complexity pruning 
path = dt_model.cost_complexity_pruning_path(X_train, y_train)
ccp_alphas = path.ccp_alphas  # Extract a range of ccp_alpha values
ccp_alphas = ccp_alphas[ccp_alphas > 0]  # Exclude zero values for pruning

# Train models with different values of ccp_alpha
best_alpha = 0
best_f1_score = 0
for alpha in ccp_alphas:
    temp_model = DecisionTreeClassifier(random_state=42, ccp_alpha=alpha)
    temp_model.fit(X_train, y_train)
    y_pred_temp = temp_model.predict(X_test)
    f1 = f1_score(y_test, y_pred_temp)
    if f1 > best_f1_score:
        best_f1_score = f1
        best_alpha = alpha

# Train the final pruned model with optimal paramet
post_pruned_dt_model = DecisionTreeClassifier(random_state=42, ccp_alpha=best_alpha)
